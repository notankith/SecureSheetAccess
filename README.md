# SecureSheetAccess

SecureSheetAccess is a Google Apps Script for Google Sheets that enables:

- User login system (username/password)
- Edit tracking by user and timestamp (on cell note)
- Sheet protection when not logged in
- Auto logout after 3 minutes of inactivity

Ideal for shared-sheet environments using a single Google account but multiple users.

## Features

- 🔐 Simple login popup before editing
- 📝 Shows who edited a cell and when (via note)
- ⏳ Auto logout on inactivity
- 🧱 Sheet protection enforcement
